導入方法

  1. Minecraft Java Editionを起動します。
  2. 「ワールド新規作成」を押します。
  3. 「その他の設定」タブから「データパック」を開きます。
  4. ダウンロードしたZIPファイルを解凍して、解凍したフォルダをデータパック画面にドラッグ＆ドロップして追加します。
  5. データパックを有効化して、ワールドを作成します。
